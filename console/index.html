This is a subset, not all of Uiua
  • In: scalars, lists, matrices, bindings, + − × ÷ =, /+, ↯ ⇌ ⧻ ⍏ ⍖ ⊏ ▽ ⊡, &matmul and the other &name OS ops.
  • Out: files, sockets, threads, modifiers beyond the list, any unimplemented glyph. That is a compile error with a line number.
  • This page steps the graph in WASM. Engine tags (neon / sme / p-core) are the compiler’s placement, not silicon running here.
  • Fusion rewrites a single-consumer Add then Multiply into one AddMul so A+B is never stored.
